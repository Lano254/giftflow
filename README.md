# GiftFlow — Sell Gift Cards for Naira & KSh

A modern, dark-themed gift card trading landing page inspired by platforms like GiftCard8. Focused on Nigerian Naira (₦) and Kenyan Shilling (KSh) payouts.

This is a front-end demo with a working mock rate calculator. No real backend or transactions are involved.

## Features

- Responsive dark fintech design
- Live-style rate calculator (mock rates)
- Toggle between ₦ and KSh
- Supported gift cards grid
- How it works section
- Demo sell form
- Ready for GitHub Pages

## Quick Start

Open `index.html` in any modern browser.

## Deploy to GitHub Pages

1. Push these files to the `main` branch in your repository.
2. Go to GitHub repository settings.
3. Open `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and the `/ (root)` folder.
6. Save.

Your site will be published at:

`https://YOUR_USERNAME.github.io/REPO_NAME/`

Example:

`https://Lano254.github.io/giftflow/`
